## How the resolver matches these portions (as of 2026-11-13)

On an exact-key, alias or memory hit the matcher never runs; `correctPortionFromMeasures` (`supabase/functions/_shared/macroResolver.ts`) turns the parsed quantity phrase into grams from the stored portions. Its `UNIT_SYNONYMS` folds bowl / cup / glass / mug into the FIRST portion whose description says "cup", and piece / slice / item / pc into the first that says piece / item / slice. **katori, plate and cutting are not units there**: for them the parser's own gram guess stands (its prompt says "1 katori/small bowl ≈ 150g", "1 plate of a single cooked dish ≈ 200g").
